# Historical LSTM baseline reference

This folder preserves the original final-state BiLSTM source and baseline configuration.
It contains the baseline source and configuration only.

The saved final-state checkpoint, metrics and ordered sample IDs are under
`results/lstm_baseline_reference_seed42/`. Current notebooks use those IDs for data audits.
Historical artifact contents retain their original recorded paths as provenance.
Run `notebooks/LSTM Baseline.ipynb` for a fresh baseline with W&B logging.
