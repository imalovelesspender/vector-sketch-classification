# 给组员的结论：统一短预算筛选

范围：345 类，每类 1,000 张训练、100 张验证，14 组各训练 5 轮。这些是验证成绩，不是 test 成绩，也不是原来计划的 20 轮完整实验。

- LSTM：加入中心化位置特征后，验证准确率从 63.27% 变为 65.20%，变化 +1.93 个百分点。
- LSTM 本轮最高配置是 lstm_geometry5_depth3，验证准确率 69.84%。
- TRANSFORMER：加入中心化位置特征后，验证准确率从 58.23% 变为 64.11%，变化 +5.88 个百分点。
- TRANSFORMER 本轮最高配置是 transformer_geometry5_depth6，验证准确率 66.23%。

本轮整体最高：lstm_geometry5_depth3，69.84%。

解释时要说“在这次数据量和 5 轮预算下的观察”。更大、更深、更多头是否有效，应对照表中同一因素的配置，不能把增加参数量的收益都归因于结构设计。还不能推出充分训练后的最优配置。原来的长任务和 checkpoint 已保留，未与本表混用。
