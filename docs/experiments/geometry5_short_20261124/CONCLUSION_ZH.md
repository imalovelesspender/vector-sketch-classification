# 给组员的结论：统一短预算筛选

范围：345 类，每类 1,000 张训练、100 张验证，14 组各训练 5 轮。这些是验证成绩，不是 test 成绩，也不是原来计划的 20 轮完整实验。

- LSTM：加入中心化位置特征后，验证准确率从 63.27% 变为 65.20%，变化 +1.93 个百分点。
- LSTM 本轮最高配置是 lstm_geometry5_depth3，验证准确率 69.84%。
- TRANSFORMER：加入中心化位置特征后，验证准确率从 58.23% 变为 64.11%，变化 +5.88 个百分点。
- TRANSFORMER 本轮最高配置是 transformer_geometry5_depth6，验证准确率 66.23%。

本轮整体最高：lstm_geometry5_depth3，69.84%。

## Depth：这轮增加层数有改善，但代价不同

- 五维 BiLSTM：1 / 2 / 3 层分别为 65.20% / 69.10% / 69.84%。
- 3 层比 1 层提高 4.64 个百分点，但参数约为 5.41 倍，本次训练加验证计时约为 2.71 倍。
- 2 层与 3 层相差约 0.74 个百分点，参数更少，因此不能只看最高准确率而忽略模型规模。
- 五维 Transformer：2 / 4 / 6 层分别为 60.08% / 64.11% / 66.23%。6 层比 4 层提高 2.12 个百分点。

## Width：加宽并不对所有模型都有帮助

- 五维 BiLSTM：每方向 hidden size 为 128 / 256 / 512 时，分别为 58.86% / 65.20% / 67.55%。本轮加宽有改善，也增加了参数量。
- 五维 Transformer：width 为 64 / 128 / 256 时，分别为 59.83% / 64.11% / 60.12%。本轮 128 最好，加宽到 256 没有收益。
- 这里 Transformer 的 FFN 宽度固定为模型宽度的 3 倍，因此 width 变化同时扩大了 FFN。不能把 5 轮筛选结果当作充分训练后的排序。

## Heads：变化较小，不支持“头越多越好”

- 固定 Transformer width=128、depth=4，2 / 4 / 8 个头分别为 64.27% / 64.11% / 64.41%。
- 三个配置的参数量相同，最高与最低相差约 0.30 个百分点。只有一个随机种子，不能称为统计显著提升。

## 如何解释输入表示

本次加入中心化 x/y 后，LSTM 和 Transformer 的验证分数都提高了。两个输入仍然以点为 token，
保留抬笔标记；没有把整条笔画压成一个 token，也没有使用 XAI 的形状、位置、顺序三路编码。
应将本次结果称为 point3 与 geometry5 的比较，不能把它表述为已经验证了所有 stroke-level 方法。

## 为什么不能拿它直接和 75%–80% 的历史成绩比

本轮每类只有 1,000 张训练草图、训练 5 轮；历史和原长任务使用了更多样本与训练轮数，
部分历史数字还来自 test。预算、样本和评估划分不同，因此低于历史分数不代表模型退步。
比较结论只在这 14 组统一的短预算内部成立。

解释时要说“在这次数据量和 5 轮预算下的观察”。更大、更深、更多头是否有效，应对照表中同一因素的配置，不能把增加参数量的收益都归因于结构设计。还不能推出充分训练后的最优配置。原来的长任务和 checkpoint 已保留，未与本表混用。
